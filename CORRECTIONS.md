# Corrections policy

Venture firms, investors and readers may submit a GitHub issue containing a factual correction and a dated primary source.

Accepted corrections can address:

- Investment stage
- Geography
- Sector focus
- Portfolio attribution
- Partner affiliation
- Framework authorship
- Broken or incorrect source links

Corrections cannot alter what a model originally returned. Historical observations remain intact and receive an attached verification or correction status.

The benchmark does not accept payment for inclusion, ranking changes or favourable interpretation.
